If you are contributing new source files to the project, please append the following header to the top of your code:

 * Copyright (c) 2026-present Sunil Kumar K V and Contributors.

### 2. Forking and Renaming Example
If you fork this project to run a public service with modifications:
1. You must rename the service so it does not use the "ChessPlay" trademark.
2. You must provide a clear link to your modified source code on the application interface, satisfying Section 13 of the AGPL-3.0.

## Best Practices
- **Respect Trademarks**: When hosting a modified instance, choose a distinct project name (e.g., "OpenChess" instead of "ChessPlay Hub").
- **Source Code Accessibility**: Place a prominent "Source Code" or "License" button in the footer of your application UI leading to your repository.
- **Upstream Collaboration**: Contribute security fixes and general game engine improvements back to the upstream repository via Pull Requests.
