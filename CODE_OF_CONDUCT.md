# ChessPlay Code of Conduct

## Our Commitment

We are committed to maintaining a respectful, professional, secure, and inclusive community.

All contributors, maintainers, reviewers, and users are expected to participate in a constructive manner.

## Expected Behavior

- Be respectful and professional.
- Assume good intent unless evidence shows otherwise.
- Focus discussions on facts, code, testing, security, and product quality.
- Accept feedback gracefully.
- Help maintain a welcoming environment.
- Report security concerns privately.

## Unacceptable Behavior

- Harassment, abuse, threats, discrimination, or hate speech.
- Publishing private information.
- Sharing secrets, credentials, tokens, or sensitive data.
- Attempting to bypass repository security controls.
- Deliberately introducing malicious code.
- Spam, phishing, or social-engineering attempts.
- Public disclosure of unpatched vulnerabilities.

## Security Expectations

Contributors must:

- Protect user privacy.
- Protect repository secrets.
- Follow responsible disclosure.
- Avoid posting exploit details publicly.
- Follow repository security policies.

## Enforcement

Repository maintainers may remove content, close discussions, reject contributions, revoke access, or take additional action when behavior violates this policy.

## Reporting

Security concerns should be reported privately.

General conduct concerns may be reported to repository maintainers.

## Scope

This policy applies to:

- Issues
- Pull requests
- Discussions
- Reviews
- Repository communication
- Community channels associated with ChessPlay
