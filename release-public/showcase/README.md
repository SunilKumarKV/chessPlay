# ChessPlay Showcase

Public showcase summary for ChessPlay v1.3.0.

## Overview

ChessPlay is a production-focused chess web app featuring Play vs AI, realtime multiplayer, responsive UI, profiles, leaderboard, premium/referral pages, and production deployment readiness.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Node.js
- Express
- Socket.IO
- MongoDB
- Stockfish
