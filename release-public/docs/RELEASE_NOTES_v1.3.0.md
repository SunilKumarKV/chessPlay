# ChessPlay v1.3.0 Public Release Notes

ChessPlay v1.3.0 is a stable production release focused on chess gameplay, AI play, realtime multiplayer, user dashboards, and production deployment readiness.

## Public Highlights

- Play chess online.
- Play vs AI.
- Realtime multiplayer rooms.
- User dashboard experience.
- Responsive web UI.
